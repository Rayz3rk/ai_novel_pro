## 构建对比

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 书架入口 JS | 830.08 KB | 245.05 KB |
| 入口 gzip | 255.87 KB | 77.89 KB |
| 最大独立 JS 包 | 830.08 KB | 445.24 KB |
| 大包警告 | 超过 500 KB | 无 |

入口 JS 体积减少约 70.5%，gzip 减少约 69.6%。编辑器和各面板的代码按实际打开情况下载，全部功能的总代码量并非按此比例减少。

浏览器验收同时检查资源列表，确认书架首屏只请求入口 JS，未提前请求编辑器、AI、模型设置或图谱；也模拟一次编辑器分包失败，确认重试后正常进入。最后一轮未限速、本机空白测试库的记录约为书架 0.59 秒、打开编辑器 0.89 秒，包含测试等待时间，仅作验收记录，不作为不同机器的性能承诺。

## 数据与验证

- 保留现有小说与导入记录；写入和删除验收使用独立临时库。
- 旧版 SQLite 自动升级不会改变章节 ID、正文或稿件版本；备份恢复包含归档章节。
- SQLite 业务回归和真实 PostgreSQL 的作品、AI、备份、归档及迁移用例覆盖外键、版本冲突与回滚。
- 最终 `pnpm test`：122 项通过、4 项 PostgreSQL 专用用例在默认模式跳过；另行使用真实 PostgreSQL 运行相关套件，54 项通过。类型检查、生产构建与 `git diff --check` 均通过。
- 桌面/移动端覆盖 390、720、1440 像素，无横向溢出；删除、归档、恢复、保留设置和加载失败重试验收通过。
- `scripts/run-ui-tests.py` 为每个浏览器验收建立全新数据和凭据目录，直接管理服务进程，结束后关闭服务，防止复用旧测试进程。

清理仅在用户确认后执行。系统保留每部作品、章节和历史版本的最后一份副本；若旧备份含有后来删除的独有章节，会继续保留。历史证据无法通过“解除关联”静默抹除，归档用于收起这些章节。模块注册和引用索引的实现说明见 [存储文档](STORAGE.md)。
