# 1.2 设定图谱版验收摘要

新增结构化卡片、有向/对称关系、布局、章节状态、方案对照、撤销与子图协作。复用资料、声音和场景规划，模型建议先待确认。

历史验收：SQLite 113 项通过、4 项 PostgreSQL 专属测试跳过；PostgreSQL 117 项通过。Windows ZIP 合计 132 项浏览器场景通过，包含卡片、图谱、冲突导出、完整备份和 16/20/24 表迁移。22 项离线案例通过，生成测试只访问本机固定样本。

验收修复了窄屏工具栏换行后的遮挡。单图最多 48 张卡片，可按邻居筛选或使用关系列表。文学质量和长期体验须另由作者评价。

仓库不含个人作品、连接、路径和原始测试审计。使用说明见 SETTING_GUIDE.md，参考取舍见 REFERENCES.md。
