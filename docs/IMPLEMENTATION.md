# 实现说明

## 工作区

- `apps/web`：React、TypeScript、正文编辑器及浏览器界面。
- `apps/server`：Fastify 本地 API、AI、资料、规划、技能与图谱。
- `packages/contracts`：共享契约及文档结构工具。
- `tests`：隔离测试、固定模型样本与浏览器流程。
- `scripts`：开发、迁移、离线评测及 Windows 打包。

SQLite 使用 Node 24 内建驱动，PostgreSQL 使用独立工作线程；同一业务服务直接读写权威数据。正文以 CAS 拒绝过期覆盖，revision 不可变，恢复前留稿；客户端应急副本按会话隔离。应用锁阻止重复进程。

完整备份包含正文、历史、规划、资料、任务和创作扩展；恢复建立独立作品并重映射标识，配置与密钥保存在项目之外。

AI 任务保存冻结材料、实际提示、调用和输出。预览不调用模型，生成、预算、取消、重试和采纳有独立记录。定稿与作者所选有效事实在同一事务提交。上下文按章节、证据、知情范围和任务类型过滤，失效来源待复核。技能包只读取受限文本，不执行脚本。

图谱沿用 story_entries 的节点标识，新增属性、链接和构思状态。atlas_relations、atlas_states、atlas_events、atlas_views 四表保存关系、剧情状态、历史与布局。资料修订和剧情演进独立；前端使用原生 SVG 与按钮，不需额外图数据库。子图仍走预览/预算/候选流程，模型建议只引用实际材料并先作为仅作者可见构思。
