# 书间 1.2 · Windows 使用说明

## 开始使用

1. 把 Windows x64 发布 ZIP 完整解压到有写入权限的目录，打开其中的软件文件夹。不要直接在压缩包里运行。
2. 双击 `start.bat`。发布包带有 Node.js 运行环境和生产依赖，不需要安装 Node、pnpm 或开发工具，也不需要联网安装依赖。
3. 保持启动窗口打开，用浏览器访问 `http://127.0.0.1:4318`。停止时在启动窗口按 Ctrl+C，等待退出。

首次运行会建立空白工作区，默认使用 SQLite。发布包不包含作者作品、真实数据库配置、API 密钥或测试库。基础编辑、保存、检索、备份和导出不依赖模型服务。

## 连接模型

在书架或 AI 助手中打开“模型连接”，填写平台地址、模型名和密钥。支持多套 OpenAI Chat Completions 兼容连接，平台预设可用于 New API、OpenAI、DeepSeek、Ollama 和 LM Studio。已运行的任务保留创建时的连接。

也可以把 `config-examples/connections.example.json` 复制到软件目录旁的 `novel-private/connections.json`，再填写自己的参数。示例中的密钥与模型为空，不会自动发起调用。API 密钥最终保存在旁边的 `novel-private/credentials/`，不进入作品备份。

## 文风与创作技能

写作台顶部“文风与技能”可管理六个内置方法、自定义副本、本书文风、人物声音和作者确认的偏好案例。AI 面板可选择本次方法与人物，并先预览材料、裁剪原因和费用；预览不会调用模型。新任务保存实际提示与技能版本，历史任务保持原记录。具体操作和受限导入格式见包内 `创作技能说明.md`。

## 数据库与数据位置

- 默认 SQLite：软件目录的 `data/workspace.sqlite`。同目录的 `*.instance-lock.sqlite` 是无作品内容的运行锁文件，请保留，程序关闭或意外退出时会自动释放锁。
- 数据库配置：软件目录旁的 `novel-private/database.json`。首次使用默认生成 SQLite 配置，已有配置不会被覆盖。
- PostgreSQL：参考 `config-examples/database.example.json`，在外置配置中填写自己的连接，选择 `postgresql`。程序可在权限允许时自行建立指定的新数据库及表；不要把新工程指向结构不同的旧项目数据库。
- 书架“数据库”入口可查看当前后端，并保存下次启动选择。修改后需关闭并重新启动。两种后端各自存储，不会持续同步。

配置文件中的数据库密码与 API 密钥均不包含在作品备份中。不要把旁边的 `novel-private` 文件夹作为公开附件分享。

## 编辑与恢复

正文会自动保存，也可按 Ctrl+S。以“已保存到本地”提示为准。模型候选需明确采纳才会更新正文；定稿与工作稿分别保留。

同一章节在多个页签打开时，未保存稿按编辑会话分别保留。刷新后如有应急副本，可预览标题、章纲、正文并选择恢复或导出。冲突时先保留自己的副本，再载入服务器稿；应急与冲突导出包含章节名称、本章意图和正文。

服务意外结束后，重新启动即可。未完成生成会显示为中断，已推送文字保留；重试创建独立候选，不自动写入正文。重复启动不能夺走仍在运行的工作区。

## 备份、升级与切换存储

书架“备份作品”导出全部作品、历史版本、资料、策划及 AI 记录。恢复会作为独立作品加入，现有作品不被覆盖。TXT/Markdown 用于可读正文导出，完整 JSON 备份用于恢复完整工作区内容。

升级前先导出完整备份、关闭旧版本，再把新包解压到新目录。需要保留原 PostgreSQL 工作区时，沿用外置连接配置并确保旧版本已经退出；使用 SQLite 时可在新版本恢复备份。确认新版本内容完整前，保留旧目录和备份。不要在程序运行中只复制一个 SQLite 主文件作为备份。

从本软件 SQLite 完整迁移到空白 PostgreSQL：关闭源工作区，在外置配置中选好 PostgreSQL，再双击 `migrate.bat`。迁移工具会取得源库锁、先保留完整 SQLite 快照，再一次性复制并逐表核对。目标有数据或源库仍在使用时会拒绝操作；原 SQLite 不被删除。迁移后重新启动并在“数据库”里核对。

命令行高级参数为 `migrate.bat --source data/workspace.sqlite --database-file ../novel-private/database.json`，相对路径以软件根目录为准。报告为 `data/storage-migration-report.json`。

## 常见情况

- 提示工作区正在使用：回到已经运行的书间；若要换版本，先关闭原启动窗口，等待退出。不要删除锁文件抢占。
- 提示端口已占用：检查是否已打开书间。可在 PowerShell 中设置 `$env:PORT='4320'` 后运行启动脚本，浏览器使用对应端口。
- 模型失败：已保存正文可继续编辑、定稿和导出。检查平台地址、模型权限与额度，再决定是否重试。
- 发布包在同一父目录内移动：启动器会重新建立本包内部依赖链接，默认相对 SQLite 路径会随软件目录使用；自定义绝对路径需自行核对。跨父目录移动已用过的软件时，请把原来的 `novel-private` 一起移到新软件目录旁，或设置 `NOVEL_DATABASE_FILE`、`NOVEL_CREDENTIAL_DIR`、`NOVEL_CONNECTIONS_FILE` 指向保留的配置与凭据。启动器发现原配置未跟随时会停止并提示，不会静默创建空白工作区。
- 文件缺失或解压不完整：重新完整解压发布包，不要从其它版本零散拷贝程序依赖。

本版面向单用户本机写作，服务只监听本机地址。多人协作、远程部署、语义向量检索及更多排版导出属于后续扩展。内容质量仍取决于模型与作者的创作判断。
