# 小说设定与关系图 · 1.2 使用指南

进入一部作品的写作台，点击顶部的 **设定与图谱**。设定属于当前小说，卡片、关系图谱、剧情时间线共用一份数据；原有“故事资料”入口继续可用。

## 从卡片开始

新建卡片可选择人物、地点、道具、组织、剧情场景或构思便签，也保留规则、事件、伏笔和剧情计划。人物可填写身份、性格、动机、背景和秘密；地点可填写环境、出入规则和上级地点；道具记录外观、用途和状态。

一时没有完整设定时，先存为便签与“构思中”，以后修改卡片类型，标识和已有连线保留。正式设定由作者明确确认。未确认构思不会自行进入普通起草任务。

人物声音关联“文风与技能”中的现有人物声音。剧情场景可关联“故事策划”中的场景规划，原规划仍是唯一内容来源。地点代表可重复使用的空间，剧情场景代表一次行动，两者可用“发生于”关系连接。

用“构思方案”区分 A/B 等备选思路。切换方案只切换尚未确认的构思，已确认设定共用。“比较构思方案”可并排查看卡片、关系和状态提案，不会调用模型。

## 画出关系

切到“关系图谱”，拖动卡片整理排布，点击“保存布局”。布局独立保存，不会修改正文或设定版本。Shift 点选或在卡片视图勾选“选入子图”可多选，最多 30 张。

选中起点，点击“从选中卡片连线”，再点终点；也可直接用“新建关系”表单。填写关系含义，如“暂时保管”“真正所有者”“信任”“活动发生于”。默认是有方向的关系；只有明确勾选“双方对称”才表示双向，甲信任乙不意味着乙也信任甲。

虚线表示构思。地点/组织的“包含”线来自卡片上级归属，修改该卡片即可调整。全部关系都有下方关系列表与编辑表单，键盘和窄屏可完成主要操作。规模较大时，用类型、搜索、章节和一层邻居缩小范围；图形一次最多显示 48 张，卡片列表保留全部资料。

## 区分编辑版本与剧情变化

“编辑关系”修正这条资料；“记录关系变化”从更晚章节建立新阶段，并结束旧阶段。例如第一章“初识”，第二章变为“搭档”。“历史与撤销”把旧版保存为新的修订，所有旧版本继续保留。

选中卡片后用“记录剧情状态”填写变化及生效章节。例如第二章道具变湿，固定档案仍保留初始状态。在“章节基准”输入 1、2 等数字查看当时关系和状态，0 查看全书。生效章节按叙事中获知/适用顺序填写；“故事时间”可另外记故事内的日期或回忆时间。

“公开信息”“仅作者知道”“指定人物知情”控制模型材料范围。人物的“仅作者知道的秘密”属性在起草和改稿材料中排除；未来章节与不符合视角的指定人物信息也不会因选中子图而绕过过滤。讨论等规划任务允许使用作者资料；作者主动写入的任务要求及正文仍按原流程作为输入。

正文事实应添加已定稿段落作为依据。旧定稿改变后显示“待复核”，相关记录不会继续作为可靠的自动材料。卡片可查看关联/提及章节与原文。文字提及按名称、别名匹配，只作为查找帮助。

## 与 AI 协作

选好子图后点击“讨论所选子图”或“围绕子图起草”，会转到 AI 面板填写要求、预览材料和费用，然后由你发起。关联的人物声音会带入本次选择，最多八个。预览本身不请求模型。

只有勾选“本次明确把构思想法作为假设”，所选当前方案的构思才进入这次任务，并标明尚未确认。已有的预算、快照、重试、候选与采纳流程继续生效。

展开“从现有规划和 AI 讨论整理资料”，可关联已有场景规划，或让 AI 提出关系建议。完成图谱讨论后，读取讨论记录，选择任务并“整理为待确认关系”。只接受本次实际提供的卡片标识；模型建议一律保存为仅作者可见的构思，保留来源讨论，重复整理不会重复添加。确认状态及知情范围须由作者核对修改。

## 保存、冲突和备份

卡片、关系、状态与布局均检查版本。遇到其它页面更新，当前填写保留，可以导出再读取最新版本；未保存关闭会提示。不要依赖关闭窗口来保存。

书架的完整 JSON 备份包括卡片、结构化属性、关系、状态、历史、布局、规划、声音与来源任务。恢复为独立作品，关联标识全部重映射。旧版无图谱的备份仍可恢复。备份不包含 API 密钥。

SQLite 与 PostgreSQL 使用相同功能；支持由使用者选择后端。此次新增四张图谱表，原有故事资料直接作为节点，无需另建一套人物数据或迁入独立图数据库。
