# 项目规划

面向单用户、本机、中文长篇创作。作者决定故事和表达，AI 帮助讨论、整理、起草、回查与修改，系统保存版本和创作依据。

创作闭环：作品设想 → 讨论与选择 → 全书/章节/场景规划 → 候选正文 → 手工改稿 → 检查与资料整理 → 作者定稿。每步允许跳过 AI；模型失败不妨碍编辑、保存与导出。

## 已实现

1. 书架、正文编辑、自动保存、留稿、恢复、定稿及导入导出。
2. 多平台连接、持久任务、流式输出、预算与明确采纳。
3. 资料证据、知情范围、分层规划及旧章影响提示。
4. 技能、文风、人物声音、偏好案例和冻结评测材料。
5. 结构化卡片、关系图、构思方案、章节状态与子图任务。
6. SQLite/PostgreSQL、完整备份、版本冲突与 Windows 发布工具。

后续混合检索、按需记忆、模型路由和更多导出格式应依据实际写作反馈推进。文学质量与长期体验需要作者评价。参考取舍见 REFERENCES.md，验收范围见 ACCEPTANCE.md。
